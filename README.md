# LinguaRoom — прототип онлайн-класса

## Что входит
- Комнаты уроков по уникальной ссылке `/?room=...`; ученик открывает ссылку и подключается к той же комнате.
- Сигнализация WebRTC через Socket.IO (без ручного копирования offer/answer).
- Видео, микрофон, демонстрация экрана.
- Совместная доска: рисование, ластик, линия, фигуры, текст, цвета, толщина, отмена/повтор, PNG.
- Чат в реальном времени.
- Домашние задания, заметки, загрузка локальных файлов и демонстрационные материалы.

## Запуск на компьютере
Нужен Node.js 18 или новее.

```bash
npm install
npm start
```

Откройте http://localhost:3000. Чтобы проверить ученика, откройте ссылку комнаты во втором браузере или в режиме инкогнито.

## Публикация в интернете
Загрузите эту папку в новый репозиторий GitHub и создайте Web Service на Render (или аналогичном Node.js-хостинге):
- Build command: `npm install`
- Start command: `npm start`
- Health check path: `/health`

После публикации сайт должен работать по HTTPS. Браузер разрешает доступ к камере/микрофону на HTTPS или localhost.

## Важные ограничения прототипа
- Сигнализация работает через сервер, а видео передаётся напрямую через WebRTC. Для некоторых сетей и мобильных операторов может потребоваться TURN-сервер; без TURN соединение не гарантируется в каждой сети.
- Данные комнат, история чата, файлы, задания и заметки пока не хранятся в постоянной серверной базе. Заметки/доска/домашние задания локально сохраняются в браузере; live-синхронизация работает пока оба участника находятся в комнате.
- Загрузка материалов в этой версии локальная: файл не передаётся на сервер и не становится доступен ученику автоматически.
- Нет аккаунтов, платежей, записи звонка, админ-панели и защиты приватных комнат. Не используйте для конфиденциальных данных без дальнейшей разработки.
- Публичный хостинг и TURN могут иметь ограничения или стоимость; проверьте условия выбранного провайдера.
